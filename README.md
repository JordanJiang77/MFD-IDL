**Dataset Description**
The data file contains the data demo extracted from Tuesday, including traffic flow, density and the adjacency matrix based on lane-level network topology.
The dataset can be achieved by https://i24motion.org/data.

**Function**
The file MFD-IDL.py is the main file for lane-level traffic flow prediction. File macro.py aggregates macro traffic state from trajectory. File MFD_calibration is used to aggregate the parameters of MFD based on the flow and density data.
